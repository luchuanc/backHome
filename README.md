# 最后一家回收站 · 1.2 回收行动

一款完整的离线单机拾荒生存游戏。离开营地，在废料场搜集零件、击退失控机械、选择强化，并在风暴到来前带着物资回家。最终修复北境灯塔。

## 开始游玩

- 独立文件：`最后一家回收站.html`，所有美术、脚本、样式和合成音频均已内嵌，可交给浏览器打开。
- 本地预览：在本目录运行 `npm start`，访问 `http://127.0.0.1:8765`。不需要安装依赖。
- 手机局域网试玩：电脑运行 `npm run lan`，手机连接同一 Wi-Fi，打开终端输出的手机地址（默认端口 8766）。电脑需保持运行。
- 开发检查：`npm test`、`npm run check`。修改源码后运行 `npm run build` 更新独立文件。

桌面支持键鼠；手机点击“开始/继续游戏”后自动进入横屏。支持系统方向锁时申请全屏并锁定横向；不支持或拒绝时，游戏舞台自行旋转，摇杆、瞄准、弹窗与营地热点保持对应。随手机方向变化自动更新，不会双重旋转。标题页保持原方向。

手机战斗使用独立布局：左上合并生命与超载，顶部显示倒计时和简短目标；右上小地图可点击放大，容量入口可打开背包整理。左下空区按下后拖动浮动摇杆，松手停止；右下大按钮冲刺并显示冷却，急救按钮显示剩余数量，靠近箱子、中继站或撤离区才出现对应交互按钮，按住执行、松手取消。底部科技入口最多预览三个图标，点击查看完整蓝图。

已验证旋转坐标与浏览器布局，尚未在实体手机上验收。手机存档独立保存在该手机浏览器；电脑旧存档不会自动同步到手机。

## 远征与营地

- 45 秒后南侧撤离区开放，可以提前带回物资。第 10 分钟风暴结束本次远征。
- 三座中继站全部激活后，可以在任一已接通中继站重新按住交互 2 秒提前唤醒守卫，也可继续准备，等第 6 分钟自动出现。第 3、5 分钟各投放医疗箱与稀有箱。
- 击败敌人后靠近掉落，拾取经验以获得三选一强化。每次远征的强化独立。
- 废铁和电路各占一格，核心占三格。范围内优先收取装得下的核心；空间不够时，“换取核心”会展示精确废铁代价，确认后一次完成腾位与拾取。电路不会被自动丢弃，未收掉落仍留在地面，手动背包整理也保留。
- 撤离保留全部背包；失败或呼叫救援保留 35% 废铁与电路，丢失全部核心。
- 4 种武器、3 种工具、16 种基础科技与 4 种进化；4 座可升至三级的营地设施。
- 修复灯塔需要曾击败守卫，并支付 120 废铁、12 电路、3 核心。完成后仍可继续远征。

营地采用可点击的场景设施，战斗采用俯视角 Canvas 画面。营地、角色、敌人、地面、建筑、道具、科技图标、进化插画与界面面板均使用 imagegen 生成的美术。文本与数值、粒子、光效、弹道和地图标记实时绘制；音乐和音效本地合成。生成提示词见 `assets/ART.md`、`assets/v2/UI-PROMPTS.md` 与 `assets/v2/world-art-prompts.md`。

## 风暴回路：科技与爆发

首次出发只介绍移动、自动射击和长按搜集。战斗目标随第一箱、第一次强化与撤离开放推进，完整生存手册随时可查。结算记录本局武器与科技，并根据真实库存展示下一项建设、所缺材料和工作台将解锁的武器；点击可直接查看对应设施。

每局有 2 次科技重抽。卡片显示升级前后数值与进化配方进度；满足配方后，后续升级会优先提供可用的进化。辅助科技与配方科技分别标识，可同时组装多个流派。

远征中打开科技蓝图可追踪一种进化。连续两次新等级的首次候选都没有该路线的缺件，下一次保证出现一张可用缺件；其余位置仍随机。重抽不推进计数，已兑现的保底配件会留在本次候选中。配方完成后优先提供所追踪的进化，但仍需玩家选择安装。换路线会清零计数，不能立即更换当前三张候选；进化安装后自动结束追踪。

| 进化 | 配方 | 战斗变化 |
|---|---|---|
| 金属风暴 | 钨钢弹芯 2 + 超频扳机 1 | 每三次射击追加两枚 70% 伤害的侧翼弹 |
| 雷暴核心 | 跃迁电容 2 + 应急电场 1 | 每两秒打击 250 范围内最多五个目标 |
| 碎冰连爆 | 冷凝剂 2 + 分裂破片 1 | 击破减速目标，引发半径 120 的冰爆 |
| 引力绞盘 | 废铁卫星 2 + 强磁线圈 1 | 每两秒牵引并伤害 220 范围内普通敌人 |

击破为超载充能，满能量进入“超载就绪”，下一次对射程内无遮挡存活敌人实际开火时启动 8 秒爆发：射击间隔乘 0.65、移动速度乘 1.12、拾取范围增加 160。清场后未开火不会空耗能量。连杀计时为 4 秒，10/25/50 连击有反馈。第 75/150/225/300 秒出现清剿波次；中继站提供经验和治疗。首级只需 45 经验，让流派更早开始成型。

旧版营地与中断远征会保留；v1/v2 远征快照自动迁移为 v3，保留背包、科技、当前候选与随机状态，补齐追踪和主动唤醒保护。已过去的敌潮不会在恢复时补刷。营地存档仍为 v1，旧日志没有构筑摘要也可读取。

## 存档

进度保存在当前浏览器的本地存储中。营地购买和结算立即保存；远征每 10 秒保存，暂停或切出页面也保存。恢复中断远征时先进入暂停界面。

设置提供 JSON 导出、导入、重置。清理浏览器数据、移动到另一浏览器或切换文件/HTTP 入口前，先导出存档。文件入口的本地存储行为取决于浏览器；保存不可用时游戏会提示导出备份。
